# React Book Collection Exercise

A React component exercise for adding book titles and authors to an in-memory list.

## ✨ Highlights

- Controlled form fields and a submit handler.
- Whitespace checks before adding a book.
- Conditional styling for long titles.

## 🚀 Getting started

Start by reading [App.js](App.js). This snapshot stores the Create React App source and public files at the repository root. Restore the expected `src/` and `public/` layout in a local working copy before using the package scripts: source modules belong in `src/`, while `index.html`, the manifest, icons, and robots file belong in `public/`.

After restoring that layout, install dependencies and run `npm start`.
